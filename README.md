## The Repository

This repository is where we develop **GNU Code IDE (GCI)** - a truly free and open-source integrated development environment, forked from Microsoft's VSCode OSS. We believe developers deserve complete freedom over their tools.

Unlike proprietary alternatives, GCI is and will always be:
- **Free as in freedom** - licensed under GNU GPL v3.0
- **Transparent** - all code is open and auditable
- **Community-driven** - no corporate agenda or telemetry

## What is GNU Code IDE?

**GNU Code IDE** is a free software distribution built from the `Code - OSS` repository, liberated from proprietary dependencies and Microsoft-specific services.

We provide developers with:
- A clean, extensible code editor with no strings attached
- Freedom to modify, study, and distribute the software
- Independence from corporate-controlled extension marketplaces
- Privacy by design - no telemetry or data collection

## Our Philosophy

### Why We Forked
While we respect Microsoft's technical contributions with VSCode OSS, we disagree with:
- Proprietary licensing of the official Visual Studio Code distribution
- Mandatory telemetry and data collection practices  
- Corporate control over the extension ecosystem
- Restrictive terms in the Microsoft Product License

### Our Promise
- **Always Free**: GCI will never contain proprietary components
- **User Sovereignty**: You control your data and development environment
- **Community Governance**: Development roadmaps are decided collectively

## Development

This repository includes development container configuration for consistent development environments.

### Using Dev Containers
Use the **Dev Containers: Clone Repository in Container Volume...** command in VS Code for optimal performance.

### System Requirements
- **Docker** with at least 4 CPU cores and 8 GB RAM
- For bare-metal setup, see [development setup guide](docs/development.md)
